### Proyectos

**[FitZone Sports](https://github.com/Martinzanandrea/FitZoneSports)** — Plataforma de gestión para una cadena de gimnasios multi-sede: control de acceso por QR, reservas de clases y canchas, membresías y pagos, con paneles diferenciados por rol. NestJS, React, PostgreSQL (Supabase). Demo en vivo: [fit-zone-sports.vercel.app](https://fit-zone-sports.vercel.app)

**ApicolaBC** — Plataforma full-stack para centralizar la operación de un negocio apícola: gestión de clientes, acopio de cera, registro de deudas y pagos, catálogo dinámico de precios, y control de inventario. NestJS, React, PostgreSQL (Supabase)

**[Gestión de Alumnos](https://github.com/Martinzanandrea/Gestion-Alumnos)** — Sistema de inscripción a cursos institucionales, con gestión de estudiantes, cursos e inscripciones, generación de diplomas en PDF, y autenticación JWT. Trabajo Final Integrador de Programación IV, Licenciatura en Sistemas (UNER). Node.js/Express, React, PostgreSQL

**[Control de Stock — Taller Municipal](https://github.com/Martinzanandrea/ControlDeStock-TallerMunicipal)** — Gestión de productos, depósitos, vehículos y movimientos de stock (ingresos y egresos), con reportes exportables a Excel/PDF y auditoría completa de acciones. Desarrollado como evaluación técnica para el Municipio de Concordia. NestJS, React, PostgreSQL

**[Portafolio Web](https://github.com/Martinzanandrea/PortafolioWeb)** — Sitio personal bilingüe, con CV generado en Typst. React, Vite. Demo en vivo: [portafolio-web-woad-omega.vercel.app](https://portafolio-web-woad-omega.vercel.app)
